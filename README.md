# 🌍 Moke Travels

**Moke Travels** is a modern frontend travel exploration web app built with **React**. It showcases stunning destinations, enables user interaction, and is tightly integrated with a Django backend (hosted in a separate repository).

---

## 🚀 Features

- 🏞️ **Home Page**  
  View a list of travel destinations with cover images and basic info.

- 🔐 **Authentication**  
  Users can register, log in, and manage sessions.

- 🗺️ **Place Detail Page**  
  Each place has:
  - A detailed description
  - Image gallery
  - Like/unlike functionality
  - Comments section

---

## 🛠️ Tech Stack

- **Frontend**: React (Vite or Create React App, depending on your setup)
- **Backend**: Django REST API (available in [another repo](https://github.com/mohd-yaseen-official/moke-travels-api.git)
- **Routing**: React Router
- **State Management**: useState/useEffect or context
- **HTTP Requests**: fetch or Axios

## 📦 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/mohd-yaseen-official/moke-travels.git
cd moke-travels
```
### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

```bash
npm start
```
Visit [http://127.0.0.1:3000](http://127.0.0.1:3000) to view the app.

**Note: The app uses a local backend API. Make sure the Django server is running on your machine and CORS is properly configured.**
